# AI Customer Support Assistant

A personal learning project exploring how AI can be used to improve customer support.

## What it does

This project simulates an AI customer support assistant that can:

* Understand customer questions
* Identify the main issue
* Generate a clear and friendly response
* Recognize when a question should be escalated to a human agent

## Example

**Customer:**

> I can't complete my onboarding because I don't know how to create a workflow.

**AI Assistant:**

> Of course! I can help with that. First, go to your dashboard and select the option to create a new workflow. If you're still having trouble, I can help you with the next steps.

## AI Prompt

The assistant follows this basic instruction:

> You are a customer support assistant. Answer clearly, politely, and helpfully. Use only the information available in the knowledge base. If you don't have enough information to answer the customer, recommend escalating the request to a human support agent.
